Big Guy's Carwash — V11 Central Sync Protection

- Firestore central data is now merged with local cache before every admin write.
- Existing employees, attendance, sales, faces, and daily reports are protected from being overwritten by an empty/stale device.
- Admin listeners merge remote data instead of replacing the current device state with a stale snapshot.
- Admin save operations update the local state with the confirmed merged Firestore state.
- New sales and attendance records receive stable IDs for safer cross-device merging.
- Employee DTR anonymous devices continue to write only attendance data.
- Face enrollment saves through the same protected central admin sync path.
- No Firebase credentials or Firestore rules were changed.
