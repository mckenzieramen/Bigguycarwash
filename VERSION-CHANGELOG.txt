V13 — Central cross-device persistence protection
- Firestore remains the central source of truth.
- Added periodic central refresh (5s) plus online/visibility refresh for Admin.
- Added realtime cloud-state event handling in Admin.
- Duplicate record merges now prefer cloud unless the local record has a newer explicit _updatedAt timestamp, preventing stale devices from overwriting newer cloud data.
- Added mutation timestamps to newly created employees, sales, daily reports, and face enrollment metadata.
- Preserved existing Firebase config, authentication, DTR, payroll, sales, face enrollment, and UI behavior.
