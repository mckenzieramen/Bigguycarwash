VERSION 93 — Employee Name Display / ID Association Fix

- Employee IDs remain internal stable identifiers.
- All employee dropdowns now display employee first/last name only when available; IDs are no longer shown in dropdown labels.
- Employee List now uses the employee display name instead of exposing the internal ID as the primary visible name.
- Added a consistent displayEmployeeName resolver using firstName + lastName, then name.
- Recovered placeholder names such as "Employee 20260909" are never displayed as the employee's name; the UI shows "Name not restored" until the actual name is restored.
- Employee NAME action is available so recovered records can be associated with their real first/last name and persisted to Firestore.
- Existing employee IDs remain unchanged and continue to be used for attendance, faces, sales, payroll and schedules.
- No Firestore collection is deleted or overwritten by this version.
